# Troubleshooting and FAQ

## Onyx Review does not appear in the sidebar

Install the release ZIP without unpacking it through **Edit > Preferences > Get
Extensions > Install from Disk**. Then open a 3D Viewport, press **N** if the
sidebar is hidden, and choose **Onyx > Review**.

If Blender reports an extension compatibility error, confirm that you are using
Blender 5.2 LTS or newer and that the downloaded file is the `onyx_review` ZIP,
not the source-code archive generated by GitHub.

## Run Review is disabled

The selected scope must contain at least one mesh. Choose **Active** for the
active mesh object, **Selected** for selected mesh objects, or **Collection** for
meshes in the active collection. The target line above the options explains
what is missing when a scope is not ready.

## Live Review says it is paused

Live Review pauses in two intentional situations:

- a target mesh is in Edit Mode; or
- the scope exceeds the configured **Live Vertex Limit**.

Leave Edit Mode to let the pending refresh continue. For a known dense asset,
raise the vertex limit or set it to zero to disable that guard. Manual **Run
Now** remains available for an immediate review.

## A finding has no Fix button

Most findings are diagnostic because the correct change depends on the model's
purpose. Fix is available only for inconsistent winding, exact duplicate faces,
loose edges, and loose vertices.

Even those actions are disabled for linked mesh data, a mesh shared by multiple
objects, or a mesh with shape keys. Make the data local or single-user only when
that is the intended production change. Onyx does not do this automatically.

## The highlight disappeared

Highlights describe the geometry at the time of the latest review. They are
cleared when the result is rerun, refreshed by Live Review, cleared, hidden, or
when a Finding View change would make the old overlay misleading. Run **Show**
or **Show Visible Findings** again to draw evidence from the current result.

Topology face and pole maps are independent from Finding View and stay visible
until another highlight replaces them or they are cleared.

## The panel and copied report do not show the same number of findings

Finding View filters only the panel and the matching viewport overview. **Copy
Report** intentionally includes every finding from the review so a handoff note
cannot silently omit hidden evidence. Switch Finding View back to **All** to see
the complete list in the panel.

## The counts changed after adding a modifier

This is expected. Base counts describe the editable source mesh. Evaluated
counts describe the result after Blender evaluates the modifier stack. Onyx
keeps both so topology diagnosis and final geometric cost are not confused.

## Report a reproducible problem

Open a GitHub issue and include:

- Onyx Review version;
- Blender version and operating system;
- the chosen review scope;
- exact steps and the expected versus actual result;
- the relevant Blender console message, if one appeared; and
- a minimal `.blend` file only when it contains no sensitive or licensed
  production data.

Use the repository's Bug Report issue form so the information arrives in a
consistent format.
